# CTI Glossary

## Introduction

This glossary contains the key Cyber Threat Intelligence (CTI) terms
used in our ransomware threat intelligence project.

The purpose of this glossary is to understand the basic terminology
used when collecting, processing, and analyzing cyber threat information.

---

## Key CTI Terms

| Term | Definition |
|---|---|
| **Cyber Threat Intelligence (CTI)** | Information about cyber threats that is collected, processed, and analyzed to help understand threats and support cybersecurity decisions. |
| **Threat** | A potential danger that can negatively affect a system, network, or organization. |
| **Threat Actor** | A person or group responsible for conducting malicious cyber activities. |
| **Threat Intelligence** | Processed and analyzed information about cyber threats that provides useful context for security activities. |
| **IOC (Indicator of Compromise)** | A digital artifact that may indicate that a system or network has been compromised. Examples include IP addresses, domains, URLs, and malware hashes. |
| **TTPs (Tactics, Techniques and Procedures)** | A way of describing the behavior and methods used by threat actors during cyber attacks. |
| **Tactic** | The main objective or goal that a threat actor wants to achieve. |
| **Technique** | The method used by a threat actor to achieve a particular objective. |
| **Procedure** | The specific way a threat actor implements a technique. |
| **Malware** | Malicious software designed to perform unauthorized or harmful actions. |
| **Ransomware** | A type of malware that prevents victims from accessing their data or systems and is commonly used to demand a ransom. |
| **OSINT (Open Source Intelligence)** | Intelligence collected from publicly available sources such as websites, reports, databases, and public security platforms. |
| **Threat Hunting** | The proactive search for evidence of malicious or suspicious activity in an environment. |
| **MITRE ATT&CK** | A knowledge base that describes adversary tactics and techniques based on real-world observations. |
| **Vulnerability** | A weakness in a system, application, or network that can potentially be exploited by an attacker. |
| **Threat Intelligence Source** | A source that provides information about cyber threats, such as security reports, threat feeds, public databases, or internal security data. |

---

## Application to Our Project

Our project focuses on ransomware threat intelligence, with LockBit
used as the main case study.

The glossary terms will be used throughout the project:

- **CTI** is the overall approach used to investigate the threat.
- **IOC** will be used to describe technical indicators such as IP addresses,
  domains, URLs, and malware hashes.
- **TTPs** will be used to describe attacker behavior.
- **MITRE ATT&CK** will be used to organize and describe attacker techniques.
- **OSINT** will be used during the data collection stage.
- **Ransomware** is the main threat category investigated in this project.
