# Week 1 — Cyber Threat Intelligence Fundamentals

## Project Topic
Ransomware Threat Intelligence and IOC Analysis

## 1. Introduction

Cyber Threat Intelligence (CTI) is the process of collecting, processing, analyzing, and using information about cyber threats to improve cybersecurity.

This project focuses on ransomware threats and the analysis of Indicators of Compromise (IOCs).

## 2. Ransomware

Ransomware is a type of malware that prevents users from accessing their files or systems and demands payment from the victim.

Common ransomware activities include:
- Initial access
- Execution
- Data encryption
- Data theft
- Extortion

## 3. Key CTI Terms

### Indicator of Compromise (IOC)
An IOC is a piece of technical information that can indicate malicious activity, such as an IP address, domain name, file hash, or email address.

### Tactics, Techniques and Procedures (TTPs)
TTPs describe how attackers operate during a cyberattack.

### Threat Actor
A threat actor is an individual or group responsible for conducting malicious cyber activity.

### Threat Intelligence
Threat intelligence is analyzed information about threats that can help organizations detect and respond to attacks.

## 4. Threat Sources

Potential sources of ransomware threat intelligence include:
- VirusTotal
- Shodan
- MITRE ATT&CKЫ
- Malware repositories
- Security research reports
- Threat intelligence platforms

## 5. Project Goal

The goal of this project is to collect publicly available ransomware intelligence, identify relevant IOCs, process the collected information, and map observed attacker techniques to the MITRE ATT&CK framework.
